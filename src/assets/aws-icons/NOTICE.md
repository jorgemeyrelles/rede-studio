# AWS Architecture Icons

Subconjunto **sem alteração** do pacote oficial "AWS Architecture Icons" (release 07/31/2026), baixado de https://aws.amazon.com/architecture/icons/ em 2026-10-17.

Termos de uso: segundo a página oficial, a AWS permite que clientes e parceiros usem esses ativos para criar diagramas de arquitetura. Valem também os AWS Site Terms (https://aws.amazon.com/terms/).
- Não editar, recortar nem recolorir os SVGs.
- Para atualizar, substitua os arquivos pelos de uma release mais nova.

Os arquivos mantêm o nome original do pacote, para que a origem de cada um fique rastreável. As cores de grupo usadas no canvas, os tokens `--aws-*` de `src/styles/global.css`, são as mesmas destes ícones.
